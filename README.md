# VELORA — Fashion Blog Final Project

A frontend-only fashion discovery + blogging website made with:
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Online Unsplash images

## Files
- `index.html` — page structure and content
- `style.css` — complete responsive styling
- `script.js` — filters, login/signup validation, favorites, search, style quiz and interactions

## Important
No database is required. Login/signup is a frontend demonstration using JavaScript validation and `localStorage`.

Images are loaded from Unsplash online, so no image files are included in the project.

## Run locally
Open `index.html` in a browser.

For the smoothest experience, use VS Code + Live Server.

## GitHub Pages
1. Create a new GitHub repository, e.g. `velora-fashion-blog`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Choose the `main` branch and root folder.
5. Save. GitHub will give you the public website URL.
