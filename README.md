# VELORA — GitHub Pages Final Project

Upload these files directly to the ROOT of your GitHub repository:
- index.html
- style.css
- script.js
- README.md
- .nojekyll

IMPORTANT:
index.html contains a fallback copy of the CSS and JavaScript, so the visual design still loads even if GitHub Pages has a CSS/JS path or cache problem. The separate style.css and script.js files are also included for your HTML/CSS/JS assignment.

GitHub Pages:
Settings -> Pages -> Deploy from branch -> main -> /(root).

Features:
- Fashion editorial homepage
- Category filters
- Favorites using localStorage
- Login form validation
- Style quiz
- Fashion journal
- Responsive mobile navigation
- Online Unsplash images
- No database required
